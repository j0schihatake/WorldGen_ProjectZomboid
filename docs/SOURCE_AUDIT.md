# Первичная проверка основы — 2026-11-05

Ungodly Random Map Generator, Workshop 3790727872, автор StixsworldHD
(StixsmasterHD4k), установленный манифест `7626935756259829306`, modversion 1.0.0.
Скачан штатным Steamworks DownloadItem для просмотра Lua, без подписки и без
включения в `default.txt`. Код основы в этот репозиторий не перенесён.

Просмотрены URMG_Main, URMG_Build, URMG_Terrain и объявления функций Plan/Canvas:

- Существующий вход `URMG_Build.submit(site)` вызывается при подгрузке участков,
  периодических проверках и повторах. Возможная точка для собственного запрета
  пересечения с картами, но размер всего будущего плана нужен до записи объектов.
- У основы есть проверки существующих построек/воды/окружения. Их наличие
  не заменяет перечень защищённых клеток модов, например незастроенную дорогу
  или резерв территории другой карты.
- Есть очередь с `opsPerTick`. Число операций не равнозначно бюджету времени:
  создание объекта, машины и группы зомби имеют разную стоимость. Нужны замеры.
- Задача помечается построенной после прохождения списка операций. Необходимо
  проверить ошибки/разгрузку квадратов и корректность частично выполненного задания.
- В просмотренных местах не подтверждено создание BuildingDef/RoomDef для новых
  помещений. Комментарий о пересчёте клетки не доказывает, что Knox распознает
  созданную постройку как убежище. Это первый интеграционный барьер перед городами.

ProcTown, Workshop 3825812871, рассмотрен только по описанию автора через Steam API:
отдельный мир, B42.21+, одиночная игра, ZombieBuddy и Building Pool V3.
Исходники не изучались, мод не скачан/не включён. Обещания работы с Project ALife
не являются подтверждением работы с Knox.

На этом этапе предпочтителен отдельный собственный адаптер/планировщик с
использованием проверенных возможностей основы. Форк пока не создан. Перед
заимствованием исходников уточнить разрешения; перед публикацией согласовать
производные материалы с автором и пользователем.
