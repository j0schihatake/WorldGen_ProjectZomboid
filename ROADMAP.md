# План PersonalWorldGen

- [x] Отдельный локальный проект и Git; не добавлять обработчики в PersonalKnox.
- [x] Собственная ограниченная проверка пересечения участка с защищёнными клетками.
- [ ] Импорт фактических клеток всех активных карт; подпись набора и версии игры.
  При неизвестной карте, изменении набора или несовпадении версии — запрет записи
  до обновления профиля. Не защищать только якорь участка: учитывать весь размер.
- [ ] Выбрать основу: готовый генератор как зависимость либо собственный планировщик
  с использованием штатных точек расширения. Не запускать два генератора одновременно.
- [ ] Проверить ограничения/разрешения основы до заимствования исходников; сохранить
  сведения об авторстве. До публикации — разрешения автора и пользователя.
- [ ] Проверить настоящие BuildingDef/RoomDef, освещение, крыши, indoor/outdoor,
  двери, окна, коллизии, навигацию и выбор убежища Knox на одном доме.
- [ ] До успешной проверки зданий разрешать только экспериментальные лагеря/руины
  на отдельном тестовом мире, не объявлять их полноценными домами для NPC.
- [ ] Защита обычных городов, модовых карт, дорог, мостов, воды, базы и построек
  игрока, убежищ NPC и посещённых участков. Не изменять текущий мир при исследовании.
- [ ] Предсказуемый seed и независимый от порядка исследования выбор участков.
  Версия генерации и конфигурация сохраняются в мире, обновление не меняет построенное.
- [ ] Новые поселения связаны дорогами; нет обрывающихся маршрутов и блокировки мостов.
- [ ] Генерация только в новых разрешённых участках, ограниченная очередь и память;
  бюджет числа операций и времени, повторная проверка участка перед записью.
- [ ] Остановка, сохранение/загрузка и восстановление прерванного задания без
  дубликатов; не помечать недостроенный участок успешно завершённым.
- [ ] Русская страница настроек: включение, плотность, размеры, seed, диагностика.
- [ ] Замер FPS/времени кадра: база, путешествие, подгрузка, бой с отрядом;
  генерация не должна отнимать неограниченное время у боевого кадра.
- [ ] Отдельная проверка с актуальным набором городов, Viewpoint, Knox и PersonalKnox.

Существующие моды карт продолжать проверять отдельно. Генератор не отменяет
совместимость клеток между самими картами и не гарантирует отсутствие вылетов.
